# Short demo note — Task 4

StudyList is a complete browser-local student task planner. The final project includes five screens, validation, local persistence, responsive styling, real screenshots, setup instructions and tests.

## One-minute reviewer walkthrough

1. Start the app using SETUP.md. A fresh installation has no tasks.
2. Select Add task and save with an empty title. The title error appears and the form stays open.
3. Enter “Submit Python assignment”, notes, today's due date and High priority. Save to see it in Today.
4. Open its details, edit the notes, then save.
5. Mark complete. In Completed, select Undo to restore it.
6. Open All tasks, search for a nonexistent title, then use Clear filters.
7. Add a task with no date/time. It appears in All tasks even if a filter was previously active.
8. Reload. The saved tasks remain.
9. Narrow the browser to phone width. Bottom navigation replaces the sidebar; priority labels remain visible.

## Task 4 polish

- Clearer form headings and inline feedback that clears after correction.
- Priority labels retained on small screens; better filter spacing and tap targets.
- Due-date/time sorting, protected malformed routes and correct singular task wording.
- Newly saved tasks are no longer hidden by an old search or priority filter.
- Unreadable storage and stale-tab writes are blocked to protect existing records.
